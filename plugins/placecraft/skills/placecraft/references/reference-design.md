# Design reference and evidence

For a new primary asset, establish one complete isolated subject with readable
construction, comfortable framing, quiet background and even lighting. Ask for
physically connected components, explicit openings and a coherent palette.
Concentrate detail where the camera can read it. Avoid fused loose props and
terrain pedestals when the reference is for a building. A composition reference
for a whole environment has a different purpose and may include terrain.

A useful prompt describes function, dominant volumes, roof profile, doors and
windows, primary materials, intended rendering style, and a few identity features.
Do not prescribe every scratch. Save the actual prompt and image together.

Inspect whether the reference is complete and buildable. Write down observations
separately from assumptions: an unseen rear window is a design decision, not
something proven by a three-quarter image. Correct implausible supports and
occlusions in the architectural plan; do not faithfully reproduce a generation
artifact. The kiln example includes a written reference critique.

When matching an established family, reuse its approved reference and material
language when that fits the task. A new image is not required for every pot or
supporting building. Historical Brookside mill/market assets derived from the
accepted family; Sunwell and Frostpass began with new generated references.

A new architectural type needs a new footprint and elevation plan even if it
shares materials. The barn initially resembled the cottage because too much
shell geometry was reused. Shared construction tools are more transferable than
an entire successful facade.
